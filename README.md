This is an IntellIJ IDEA project that combines all of my Markdown-related projects together. That allows me to evolve them together, e.g. with synchronized branches.

I keep the separate projects locally *next to* the project root, not under it. Each project can be opened and worked on independently.

This project requires the following projects to be checkout out next to it:

- [alfred-markdown-curator-template](https://github.com/voostindie/alfred-markdown-curator-template)
- [markdown-curator](https://github.com/voostindie/markdown-curator)
- [markdown-curator-demo](https://github.com/voostindie/markdown-curator-demo)
- [marked-markdown-curator-filter](https://github.com/voostindie/marked-markdown-curator-filter)
- [obsidian-alfred-trigger-plugin](https://github.com/voostindie/obsidian-alfred-trigger-plugin)
- [vincents-markdown-curator](https://github.com/voostindie/vincents-markdown-curator)
